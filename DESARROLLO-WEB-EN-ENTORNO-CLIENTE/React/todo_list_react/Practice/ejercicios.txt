Ejercicio 6: Custom hook useTodos
Revisar src/hooks/useTodos.js.
Ahí está el estado todos y las funciones addTodo, toggleTodo, deleteTodo,
editTodo y deleteCompleted.
En src/components/pages/TodosPage.jsx ya no está esa lógica: solo se llama

El hook es .js porque no devuelve JSX; es lógica reutilizable.
